Vector clock rules

  1. Local event: Increase the process's own clock value by 1.
  2. Send event: Increase the sender's own value and attach its vector clock to the message.
  3. Receive event: Take the maximum of both vectors, then increase the receiver's own value.
  4. Causality: A is before B if every value in A is less than or equal to B and at least one is smaller.
  5. Concurrency: If neither vector is before the other, the events are concurrent.
